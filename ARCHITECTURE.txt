Flujo de datos
--------------
main.dart -> PokedexScreen(repository: HttpPokemonRepository())
  Lista:    PokedexScreen -> PokemonRepository.fetchPage(limit, offset) -> [PokemonSummary]
            -> se ordena por id -> PokemonCard(PokemonSprite)
  Detalle:  tocar una tarjeta o buscar por nombre -> PokemonDetailScreen
            -> fetchPokemon(name) -> PokemonDetail.fromJson

Decisiones de diseño
--------------------
- La UI depende de PokemonRepository (abstracción), no de http: en los tests se usa un fake.
- fetchPokemon se inyecta en PokedexScreen mediante PokemonFetcher.
- Los widgets de presentación son StatelessWidget; el estado vive en PokedexScreen.
- El sprite de la lista se arma con el id, sin llamadas extra a la API.
